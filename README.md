# nba-analytics-pro
NBA Analytics Pro - NBA Statistics, Team Analysis &amp; Game Predictions

### 球員身世與背景

在戰績表點選球隊，再點選「查看球員資料與背景」，即可查看出生日期、出生地、來源記載的學校、NBA 初登場年份、選秀、生涯球隊及獎項。背景資料取自 ESPN 公開球員頁與資料端點，與即時比賽數據分開呈現；缺漏欄位顯示「未提供」，不從出生地推測國籍，也不把就讀學校當作畢業學位。

`data/biographies.json` 保存逐球員來源及更新時間。每日台灣時間 15:00 的既有流程會執行 `scripts/update_biographies.py`；來源失敗或覆蓋率不足時保留舊快照，不阻擋原本統計更新。這是每日資料快照，並非即時個人資訊。

`data/player_stories.json` 另收錄 12 位球員的繁體中文人物摘要，每則附公開來源與查核日期。這些故事採人工查核，**並非所有球員都有家庭故事，也不會自動產生未經查證的傳記**；沒有可靠來源時會明確標示。新增故事應確認球員 ESPN ID、逐項核對原始採訪或官方資料，並保持簡短摘要與原文連結。
