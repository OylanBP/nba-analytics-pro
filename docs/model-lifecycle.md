# NBA 勝率模型自動維護（開發中）

本分支新增 **可執行的模型生命週期基礎**，並非已完成 v2.0。

## 自動流程
- 每週一 UTC 07:20（台灣 15:20）檢查資料並評估模型。
- 每月第一個週一嘗試訓練新模型。
- 新模型只有在相同時間切分測試集上 Brier Score 改善至少 0.001、Log Loss 沒有顯著惡化時才替換舊模型。
- 資料缺失、少於 200 場、特徵非法或日期異常時停止；不會製造假數據或假準確率。
- 只在有資料時輸出評估結果，並嘗試提交到儲存庫。

## 尚未完成的關鍵工作
1. 建立**真實且可重現**的 NBA 歷史比賽與賽前特徵資料擷取流程，並確認來源授權、完整性與資料洩漏風險。
2. 在 `data/model/games_history.json` 提供至少 200 場真實已完賽紀錄；每筆包含 `date`、`home_team`、`away_team`、`home_win`、`home_win_pct_before`、`away_win_pct_before`、`home_rest_days`、`away_rest_days`。所有特徵必須是**開賽前已知**的值。
3. 加入滾動式、真正樣本外回測；目前單一 holdout 的反覆選模有過度擬合風險，不能據此宣稱正式模型準確率。
4. 加入未來賽程資料、每日勝率預測 JSON、前端呈現及部署驗收。
5. 與現有台灣時間 15:00 資料更新流程整合，確認排程與寫入權限。
