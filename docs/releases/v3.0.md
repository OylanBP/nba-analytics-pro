# NBA Analytics Pro v3.0

預測頁會顯示官方傷兵名單、報告時間及該場採用的模型。雙方資料齊全時可計算傷兵調整。球員角色取自 ESPN 歷史逐場上場時間與得分，依當季、同隊、開賽日以前最近十次出賽估計。至少三場才建立角色資料，未確認球員保留人數資訊。

球員角色候選模型與人數模型以同批、時間順序切分的比賽評估。候選模型需有足夠可配對球員的測試場次，且布里爾分數及對數損失皆優於人數與原始模型才可調整正式機率。預測頁列出實際評估結果。上場時間與得分反映近期角色，未直接量測單一球員對勝負的因果影響。

傷兵報告每五分鐘排程檢查，已開啟的預測頁每分鐘檢查更新。戰績、陣容與比賽資料維持台灣時間每日 15:00 排程更新。
